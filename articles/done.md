Some time ago, models used to take a widely variable time to complete a task,
ususally between ten seconds and ten minutes. This kept me glued to the screen,
mostly just waiting for it to be done. Then I got the idea to tell Claude that
when it's done, it should print a big "DONE" banner so I can see it from the
other side of the room. I ended up collecting several different versions of this
banner as they came out of the model.
